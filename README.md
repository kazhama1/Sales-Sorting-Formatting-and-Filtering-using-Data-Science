📌 Project Overview

This project focuses on analyzing raw sales data using Microsoft Excel by applying data science techniques such as data cleaning, sorting, filtering, visualization, and forecasting.

The goal is to transform unstructured and inconsistent data into meaningful insights that support better business decision-making.

⸻

❗ Problem Statement

Sales data in many organizations is often:
	•	Incomplete (missing values)
	•	Duplicated
	•	Inconsistently formatted

These issues make accurate analysis difficult and can lead to poor business decisions.

⸻

🎯 Objectives
	•	Clean and organize raw sales data
	•	Apply sorting and filtering for better data exploration
	•	Analyze trends using pivot tables and charts
	•	Predict future sales using forecasting techniques
	•	Support data-driven decision-making
⸻

⚙️ Methodology

1. Data Cleaning
	•	Removed duplicate records
	•	Handled missing values (average/estimated values)
	•	Standardized text formats (UPPER, PROPER)
	•	Corrected date formats
	•	Trimmed extra spaces
